# OSdep Release 1.2.0

## What's New

Major overhaul of the build system and platform detection. The build system has been converted from MakeMe to a standalone Makefile with no external tool dependencies. OS detection now uses numeric constants for cleaner conditional compilation.

### New Features

- Numeric OS type constants (`ME_OS_TYPE`) with 21 OS constants from `ME_OS_UNKNOWN` through `ME_OS_SOLARIS`
- Platform detection uses `ME_OS_TYPE == ME_OS_LINUX` instead of string comparisons
- Windows on ARM support via `_M_ARM64` compiler detection
- `ME_HAS_SENDFILE` platform detection for zero-copy file transfers (Linux, macOS, FreeBSD)
- Malloc heap stats headers for Linux (`malloc.h`) and macOS (`malloc/malloc.h`)
- `stdbool.h` included on Linux for proper bool support
- `stdint.h` included on all platforms
- ESP32 and FreeRTOS platform support improvements
- Default feature flags (`ME_COM_SSL`, `ME_DEBUG`, `ME_FLOAT`, `ME_ROM`) moved to top of `osdep.h`

### Bug Fixes

- Fixed architecture definitions
- Fixed bool type handling across platforms
- Fixed Windows compatibility issues
- Fixed `stdatomic` in C++ builds
- Fixed FreeRTOS includes

### Improvements

- Converted build system from MakeMe to standalone Makefile
- Removed validate.c, IDE project files, and Premake5 configuration
- Simplified Makefile to utility targets only (header-only module)
- Rewritten README with platform detection, types, and make target documentation

### Breaking Changes

- Build no longer uses MakeMe or Premake5; use `make` directly
- Removed `src/validate.c` and IDE project files (gmake2, vs2022, xcode)
- OS detection code should migrate from string-based `ME_OS` comparisons to numeric `ME_OS_TYPE` constants
